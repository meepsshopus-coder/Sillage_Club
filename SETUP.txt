IMPORTANT
The HTML preview by itself cannot run Stripe Checkout. The /api function must be deployed on a serverless host such as Vercel. Vercel supports API functions in an api directory. Use Node 24 for new deployments.

STRIPE VALUES YOU WILL ADD IN VERCEL
STRIPE_SECRET_KEY = your Stripe TEST secret key
STRIPE_PRICE_DIOR = the Price ID for Dior
STRIPE_PRICE_LIBRE = the Price ID for Libre
STRIPE_PRICE_JPG = the Price ID for Le Male Elixir
STRIPE_PRICE_LAYTON = the Price ID for Layton
STRIPE_PRICE_AVENTUS = the Price ID for Aventus
STRIPE_SHIPPING_US = your $4 shipping rate ID
STRIPE_SHIPPING_INTL = your $10 shipping rate ID
STRIPE_SHIPPING_AZ = your $0 Arizona shipping rate ID
SITE_URL = the deployed website URL

DO NOT put STRIPE_SECRET_KEY into index.html or send it to anyone.

ARIZONA
The storefront asks for a ZIP when Arizona local is selected and validates that it looks like an Arizona ZIP before creating the session. Stripe also collects the customer's shipping address. Because this is a client-selected local-delivery flow, review the final shipping address when fulfilling local orders.

DEPLOYMENT
1. Create a Vercel project from this folder.
2. Add the environment variables above in Vercel Project Settings > Environment Variables.
3. Add them first to Preview/Test while Stripe is in Sandbox/Test mode.
4. Deploy.
5. Open the Vercel URL and test the bag.
6. Test one product and then multiple products.
7. Confirm U.S. shipping is $4 and international is $10.
8. Test Arizona local with an Arizona ZIP.
9. Only after all tests pass, create the corresponding LIVE Stripe products/rates and replace the TEST environment values with LIVE values.
